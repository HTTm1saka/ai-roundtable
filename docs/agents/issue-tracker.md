# Issue tracker: GitHub
Issues and specs live in HTTm1saka/ai-roundtable.
Use gh from this checkout; verify the target with gh repo view before creating issues.
Use --body-file for multiline issue bodies and comments.
Read with gh issue view; list with gh issue list; edit labels with gh issue edit.
Before closing, post the resolution as a comment.
Represent blocking relationships with native issue dependencies when available,
otherwise add a "Blocked by: #<number>" line.
PRs as a request surface: no.
