添加 AI

为这位参与者配置独立的模型与视角。

使用 ChatGPT 套餐包含的 Codex 额度。先在项目终端运行 npm run login:chatgpt，在浏览器完成登录，然后检查状态。无需填写 API Key；额度不足时暂停。

填写带版本的 API 根路径，如 …/v1；也接受完整 …/chat/completions，不会重复拼接。密钥请填在下方，不要放入 URL。

记住后会将密钥保存至 IndexedDB；能访问此浏览器数据的人或页面脚本可以读取。导出备份不包含密钥。

订阅模式可留空，使用 Codex 默认模型；也可填写账户可用的 Codex 模型 ID。流式按 Codex 消息事件更新。

默认跟随模型设置。更高程度通常需要更多时间和额度；实际支持的档位由模型和服务商决定。不支持时请选择“跟随模型”后手动重试。切换接入方式时，不兼容的档位会恢复为默认。
